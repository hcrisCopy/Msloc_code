Compare Text A (the model's Explanation) with Text B (the GT reference descriptions) and evaluate the following three dimensions.

Text B contains Main and may also contain Start and End. Each entry gives a subject, category, subcategory, and description. Only Main may have multiple entries. If Text B contains multiple Main entries, select the Main entry most semantically relevant to Text A and exclude only the other Main entries in Text B from scoring. If Text B contains a single Main entry, use that Main entry directly.

For each of the three dimensions, evaluate the complete Text A using the same selected Main entry from Text B together with Text B's Start and End descriptions, when provided. Return one score per dimension based on this combined reference. If Text B contains only Main, evaluate main-event content only; start/end details are outside the reference's coverage. Fluency is evaluated separately.

object_accuracy (Anomalous Object Accuracy):
5: The described anomalous object matches the relevant reference object or its core part.
4: The object description is overly broad or slightly imprecise but relevant.
3: It is only loosely connected to the reference object.
2: The main object is substantially wrong, or no anomalous object is identified.
1: The described anomalous object is unrelated to the reference.

anomaly_type_accuracy (Anomaly Type Accuracy):
5: The described anomaly matches the reference category and its defining characteristics.
4: The anomaly is recognized but expressed vaguely.
3: A related anomaly is described, but its primary nature is missed.
2: The principal anomaly type is substantially wrong or omitted.
1: The explanation gives an opposite or unrelated anomaly, or explicitly denies the annotated anomaly.

detail_consistency (Description Consistency & Detail Accuracy):
5: Core details and applicable before/after state changes agree with the reference.
4: Core details are covered, but a specific change direction or a minor detail is missing, or there is minor redundancy.
3: The explanation is generic and lacks the reference's important specifics.
2: Important details or state changes contradict the reference.
1: Severe contradictions or reversed changes undermine the explanation.

Each reason should identify the specific agreement, imprecision, omission, or contradiction supporting the score.
Return exactly these keys: object_accuracy, anomaly_type_accuracy, detail_consistency.
